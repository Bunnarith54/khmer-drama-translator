# 📱 Build APK from a Phone — Khmer Drama Translator v2.7

This is the simplest phone-only route. GitHub builds the APK on its servers.

## A. Create the GitHub repository
1. Open github.com in Chrome on Android and sign in.
2. Create a **New repository**. A private repository is recommended.
3. Open the new repository.

## B. Upload this project
1. Download the v2.7 ZIP.
2. Extract the ZIP on your phone using Files/ZArchiver.
3. In GitHub, choose **Add file → Upload files**.
4. Upload the **contents inside the project folder**, not the outer folder itself.
5. Commit the files to the `main` branch.

## C. Start the APK build
1. Open the repository's **Actions** tab.
2. Choose **Build Khmer Drama Translator APK**.
3. Tap **Run workflow → Run workflow**.
4. Wait until the job has a green check.
5. Open the completed run.
6. Scroll to **Artifacts**.
7. Download **Khmer-Drama-Translator-debug**.
8. Extract it and install the `.apk` on Android.

## If Actions is not visible
Push/commit the `.github/workflows/build-apk.yml` file first. GitHub may take a short time to activate Actions for a new repository.

## What this APK is
- It is a real Android APK generated by Capacitor + Gradle on GitHub's Linux runner.
- It is a **debug/testing APK**, not a Play Store release.
- It does not contain the Gemini secret key.

## Backend requirement
The APK is only the mobile client. Translation, TTS, Demucs and FFmpeg require the backend to be online and reachable over HTTPS. Configure the backend URL before testing those functions.

## If the build fails
Send a screenshot of the red error from the Actions run. The error log is enough to diagnose the next step.
